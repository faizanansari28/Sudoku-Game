# Sudoku Game

## Project Overview

This project is a Sudoku Game developed using C++ as a programming project. It focuses on implementing the basic logic and functionality of the Sudoku puzzle.

Sudoku is a number-placement puzzle in which the objective is to complete a 9x9 grid by filling empty cells with numbers from 1 to 9 while following the rules of the game.

## Technologies Used

- C++
- Visual Studio
- Standard C++ Libraries

## Game Rules

The Sudoku puzzle follows these basic rules:

- Each row must contain numbers from 1 to 9 without repetition.
- Each column must contain numbers from 1 to 9 without repetition.
- Each 3x3 subgrid must contain numbers from 1 to 9 without repetition.
- Every empty cell must be filled with a valid number according to Sudoku rules.

## Project Structure

The repository contains the following files:

- `sodoku.cpp` - Main C++ source code containing the game implementation.
- `game.sln` - Visual Studio solution file.
- `game.vcxproj` - Visual Studio project configuration.
- `game.vcxproj.filters` - Project file organization settings.
- `game.vcxproj.user` - User-specific Visual Studio settings.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `game.sln` using Microsoft Visual Studio.
4. Build the project.
5. Run the application to start the Sudoku Game.
